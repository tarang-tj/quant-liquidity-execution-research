# Terminology and data dictionary

| Term | Symbol / field | Definition | Units / valid range |
|---|---|---|---|
| Parent order | $Q$ | Total shares that must be sold by horizon end | shares, positive |
| Child order | $x_t=Qv_t$ | Shares sold in decision interval $t$ | shares, $0\le v_t\le c_t$ |
| Execution fraction | $v_t$ | Fraction of parent order sold in decision interval $t$ | fraction, $[0,1]$ |
| Remaining inventory fraction | $r_t$ | Fraction still to sell immediately before decision $t$ | fraction, $r_1=1$ |
| Liquidity regime | $z_t$ | Generator-only hidden state: 0=calm, 1=stressed | binary |
| Stress posterior | $p_t$ | Causal filtered probability $P(z_t=1\mid y_{1:t})$ | probability, $[0,1]$ |
| Observation vector | $y_t$ | Log trailing volatility, log quoted spread, log displayed depth | standardized features |
| Spread | $s_t$ | Synthetic bid–ask spread proxy | basis points, positive |
| Depth | $d_t$ | Synthetic displayed liquidity proxy | shares, positive |
| Volatility | $\sigma_t$ | Synthetic intrainterval volatility and post-trade shock scale | basis points / interval, positive |
| Transition matrix | $P$ | Probability of switching/remaining in a liquidity state | each row sums to 1 |
| Temporary impact | $\eta_t$ | Quadratic immediate execution-cost coefficient in normalized IS formula | bps / fraction² |
| Executable participation cap | $c_t$ | Observed, depth-derived maximum parent-order fraction executable in interval $t$ | fraction, $[0,0.18]$ |
| Risk aversion | $\lambda$ | Weight converting variance of unexecuted normalized inventory to bps cost | $1/\mathrm{bps}$ |
| Implementation shortfall | IS | $\sum_t\eta(z_t)v_t^2+\sum_t r_{t+1}\epsilon_t$: arrival-price-relative temporary impact plus post-trade inventory noise | basis points of notional |
| CVaR$_{0.95}$ | CVaR | Mean of the worst 5% of implementation-shortfall outcomes | basis points of notional |
| TWAP | — | Equal-size schedule, capped and feasibility-adjusted | baseline policy |
| Static AC-like | — | Unconditional-coefficient impact/risk schedule | baseline policy |
| Regime-aware MPC | — | Receding-horizon schedule using only current posterior | proposed policy |
| Common random numbers | CRN | Same seeded market paths for all policies | variance-reduction design |
| Causal evaluation | — | Decision at $t$ cannot use $y_{t+1:T}$ or $z_t$ | required information constraint |

## File-level data dictionary

| File | Key fields | Role |
|---|---|---|
| `data/synthetic_market.csv` | `path_id`, `t`, `regime_true`, `log_trailing_vol`, `log_spread`, `log_depth`, `capacity_fraction`, `price_shock` | Generated market observations; all except `regime_true` and `price_shock` are available before the decision |
| `results/filter_diagnostics.csv` | `posterior_stress`, `regime_true`, classification fields | q1 filter validation |
| `results/path_costs.csv` | policy, path, IS, completion, max violation | q2 path-level evaluation |
| `results/summary_metrics.csv` | policy, mean IS, sample standard deviation, VaR, CVaR | q2 aggregate evaluation |
| `results/online_learning_metrics.csv` | retraining cycle, learned transition estimates, independent holdout quality, tail-cost and feasibility checks | q3 continual-calibration evaluation |
| `results/sensitivity.csv` | scenario, policy, mean IS, CVaR | stress and parameter sensitivity |
